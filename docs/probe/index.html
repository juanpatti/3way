WebMCP probe

This page reports what the browser you are reading it in can actually do. It is the instrument published at /probe/ that produced the measurements quoted on 3way.dev — the same file, published rather than described, so you can get your own answer instead of taking ours.

“Probe Click” only means something when an agent clicks it. A person clicking reports isTrusted=true, which proves nothing — you are a person. The finding is that an agent driving the page reports true as well, so the page cannot tell you apart. To see it, ask your agent to open this page and press that button. Results already recorded across three runtimes — ChatGPT's in-app browser, an agent-spawned Chrome tab, and plain Chrome — live in the runtime findings.
